# Visual worsening and ADL: supporting source data

Supporting data for **Self-Rated Visual Worsening and Subsequent Activities of Daily Living Limitation or Death Across Four Cohorts**.

`Supplementary_Data_1.xlsx` contains aggregate analytical results, supporting tabulations, and figure source data. Participant-level cohort datasets are not included.

## Files and navigation

- `Supplementary_Data_1.xlsx`: the complete workbook, containing 21 worksheets. Start with `Contents` for its internal navigation links.
- `WORKSHEETS.csv`: an index of the 20 data and dictionary worksheets, with their existing descriptions and data ranges.
- `SHA256SUMS`: the SHA-256 checksum of the workbook.
- `file_manifest.json`: the workbook filename, size, checksum, manuscript title, and worksheet count.

Field definitions and units are provided in the workbook's `Data_dictionary` worksheet. Worksheet names and data ranges in `WORKSHEETS.csv` reproduce the workbook index, allowing individual results to be identified by worksheet name and cell range.
